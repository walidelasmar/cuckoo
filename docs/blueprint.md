# **App Name**: Profit Palate

## Core Features:

- Restaurant Account Management: Secure user login and registration, allowing each restaurant to manage its unique data and settings.
- Raw Material Catalog: Enable creation, viewing, editing, and deletion of raw material inventory items. Fields include Category, Name, Short Name (unique identifier), Provider, SKU, Quantity, predefined Unit options (common kitchen volumetric and weight units), Price, and an automatically calculated Price per Unit.
- Recipe Definition & Management: Tools to create, view, and edit recipes. Users specify recipe name, category, description, and the target number of portions. Ingredients are added by selecting from the raw material catalog, each with a specified quantity and a compatible unit.
- AI Unit Assistant Tool: Provides real-time guidance when selecting units for recipe ingredients. This tool ensures compatibility between the selected raw material's base unit and the recipe ingredient's specified unit, offering suggestions for relevant culinary conversions.
- Cost & Margin Calculator: Automatically calculates the total cost per recipe and the cost per portion based on the prices of raw materials and specified ingredient quantities, forming the foundation for profit margin analysis.

## Style Guidelines:

- Primary color: Muted Forest Green (#668C3D). This desaturated, earthy green evokes reliability, growth, and subtle culinary professionalism, providing a calm yet authoritative brand presence.
- Background color: Whisper Green (#F2F6E9). A very light, highly desaturated green derived from the primary hue, offering a clean, airy, and unobtrusive backdrop for data and forms.
- Accent color: Goldenrod (#E0D12E). This bright, warm yellow-green provides a vibrant contrast, drawing attention to important call-to-actions, highlights, or key financial insights.
- Headline and body font: 'Inter' (sans-serif). Chosen for its high legibility across various screen sizes and its modern, neutral, and efficient aesthetic, making it ideal for data-heavy applications and professional documentation.
- Utilize a set of clear, concise, and functional line icons throughout the interface to intuitively represent actions, navigation, and content categories, maintaining a professional and consistent visual language.
- Employ a clean, structured, and spacious layout. Content should be organized into easily digestible sections, potentially using a card-based system for recipes and materials, ensuring clarity and ease of navigation for complex data entry.
- Incorporate subtle and smooth transition animations for page changes, form submissions, and interactive elements. These animations are designed to enhance user feedback and perceived responsiveness without causing distraction.
